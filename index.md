# Rclone Drive

Aplicativo pessoal utilizado para sincronizar arquivos entre minha conta Google Drive e meu computador Linux Mint.

## Finalidade

O aplicativo utiliza a Google Drive API para acessar, baixar, enviar e sincronizar arquivos mediante autorização do proprietário da conta Google.

O aplicativo é destinado exclusivamente ao uso pessoal e não é disponibilizado comercialmente.
